Table image to spreadsheet with chart · Nepali text translated to English

Convert a table image to Excel

Upload a photo or screenshot of a table. The app reads the cells, translates Nepali text to English (English stays as it is), and produces an Excel workbook with the data table, a summary table and charts.

Server: checking…

This page is served over HTTPS, so the browser blocks a plain http:// server address. Use an https:// server address.
Advanced: conversion server

Leave empty to use the default server published with this page. Any deployment of the image-to-xl repository works.
