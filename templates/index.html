Convert a table image to Excel

Upload a photo or screenshot of a table. The app reads the cells, translates Nepali text to English (English stays as it is), and produces an Excel workbook with the data table, a summary table and charts.

API

Send an image and receive the workbook directly:

curl -F image=@table.jpg {{ request.host_url }}api/convert -o table.xlsx

Add ?format=json to get the extracted rows as JSON plus a download link.
